首个公开版本（1.8.0）。把斗地主完整搬到 Charta 的牌桌上，并把界面、世界里的那张牌桌与发布流程都收拾干净。

## 玩法

- **抢地主（默认）/ 叫分**两种定地主方式，选项里一键切换。
- **明牌 / 加倍**：两个独立开关，叠满个人倍数 ×4；结算是逐对的，永远零和。
- **完整牌型**：单张 / 对子 / 三张 / 三带一 / 三带二 / 顺子 / 连对 / 飞机（带单或带对）/ 四带二 /
  炸弹 / 王炸，边界口径（翅膀、四人局炸弹张数等）显式建模并有测试覆盖。
- **计分**：底分、炸弹与王炸翻倍、春天 / 反春天，跨局累计记分板。
- **三档 AI 难度**：保守 / 均衡 / 激进，只改风格与紧迫感，不改规则。

## 界面

- **记牌器**：每个点数还剩几张没露面，由「你能看到的一切」推算。
- **看牌界面**（`看牌` 徽章或 `V`）：一页摊开每家的手牌与底牌——自己与已明牌的座位画正面牌，
  其余座位按真实张数画牌背；正面牌有悬停立体感与牌名 tooltip，看牌时背景音乐不断。
- **手牌拖拽排序**：牌跟着鼠标走 + 插入位置指示线，落点与指示线共用同一支扇形算法。
- **修掉两个点击问题**：点第二行的牌却选中第一行、点上一手与底牌重叠处会「拿起」上一手的牌。
- **底牌改为面板右上角的小牌预览**，把整行高度还给牌桌；**桌面上不再摊开底牌**，
  改成地主面前一张横放的扣牌当地主标记（真正的底牌仍摊在界面里）。
- 牌背重新绘制：金线描边 + 细菱格 + 中央金冠徽章；项目图标与游戏图标同一套美术。

## 世界里的那张牌桌（不开界面也能看懂）

- 各家扇形整局保留、待在**自己的牌槽**里；**轮到谁就把谁的扇形往桌心推 0.19 格**，换人时上一家退回。
- **上一手牌偏到出牌者那一侧、并正面朝着他**（不同人出的牌朝向不同，收桌后回中）。
- 地主面前一张横放的扣牌 = 地主标记；它由「地主自己出牌区的落点」推出来，永远夹在扇形与出牌之间。
