# ChartaLandlords

在 [Charta](https://modrinth.com/mod/charta) 的牌桌上开一局**斗地主**：3 人局（54 张）与 4 人局（108 张两副牌）。
含抢地主 / 叫分、明牌 / 加倍、完整牌型判定、逐对结算与跨局记分板、记牌器与看牌界面、三档 AI 难度，
以及一段现场合成的中国风 BGM。仓库首页见 [工作区 README](../../README.md)。

## 怎么玩

1. 摆一张**牌桌**与 3~4 把**游戏椅**（朝向牌桌）。
2. 自己坐一把；对手可以是真人，也可以把生物（村民、牛等）用牵引绳拉住后右键椅子让它坐上去——坐着的生物会自动出牌。
3. 放对应牌堆：**斗地主牌堆（54 张）** 打 3 人局，**斗地主双副牌堆（108 张）** 打 4 人局（人数与牌堆不匹配无法开局）。
4. 右键牌桌选「斗地主」→ 决定地主 →（可选的明牌 / 加倍）→ 出牌。
5. 点手牌选牌，按「出牌」（**回车**）、「不出」（**空格**）、「提示」自动选出能压过上一手的最小牌型；
   **V** 打开看牌界面；手牌可**按住拖动排序**。

界面左上角的 `?`（玩法）里有完整规则、全部牌型与计分说明，中英双语。

## 规则摘要

* **人数与牌堆**：3 人 = 54 张（每人 17 + 底牌 3）；4 人 = 108 张两副牌（每人 25 + 底牌 8）。
* **定地主**（选项里切换，**默认抢地主**）：
  * **抢地主**：一轮「抢 / 不抢」，底分固定 1，每次抢翻一倍，**最后一个抢的人**当地主（第一个抢的不额外翻倍，
    所以抢 n 次记 n−1 次翻倍）；没人抢则重新发牌，连续两轮无人抢就指定手牌最强者。
  * **叫分**：按座位各叫一次，必须高于当前最高分，叫 3 分立即结束；无人叫分重新发牌。
* **明牌 / 加倍**（地主确定后，可关）：10 秒窗口内每人两个**独立开关** + 确认。
  **明牌**把手牌公开（×2，单向不可撤），**加倍**只加注码（×2，可反复切换），两个都开 = ×4。
  到点未确认者按当前开关状态结束，不会有人挂机卡住整桌。
* **牌型**：单张 / 对子 / 三张 / 三带一 / 三带二 / 顺子（5~12 张，3~A）/ 连对（3~12 对）/
  飞机（2~6 个三张，带等量单张或对子）/ 四带二（6 或 8 张）/ 炸弹 / 王炸（4 人局为四张王）。
* **比较**：同型同长比关键点数（3<4<…<K<A<2<小王<大王）；三带 / 四带 / 飞机按**主体**比，与带牌无关；
  炸弹压任意非炸弹，张数多者大，王炸最大。
* **边界口径**（各家写法不一，代码里显式建模）：飞机翅膀可以恰好是一对、但同一手不能混用单翅膀与对翅膀；
  四带二的两张单牌可以是一对；大小王不能同时当带牌；四带二只和同型比、但会被炸弹压。
* **计分**：`单位分 = 底分 × 局倍数`，地主与**每个农民逐家单独结算**（3 人局 ±2 份、4 人局 ±3 份，永远零和）。
  局倍数 = 炸弹/王炸各翻一倍 × 抢地主 n−1 次翻倍 × 春天 / 反春天；个人倍数（明牌、加倍）只放大自己与地主那一份。
  结算播报在聊天栏，跨局累计分数显示在座位条右侧（第 1 局结算前显示 0）。可在选项里关掉计分。

## 选项（Charta 原生「选项」界面，每张牌桌独立）

| 选项 | 默认 | 作用 |
| --- | --- | --- |
| 允许三带一 / 三带二 | 开 | 关掉后三张只能单独出 |
| 允许四带二 / 四带两对 | 开 | 关掉后四张同点只能作炸弹 |
| 四带二的「二」可以是一对 | 开 | 关掉后必须是两张不同点数的单牌 |
| 允许大小王同时当带牌 | 关 | 开启后 `333 + 小王 + 大王` 合法 |
| 飞机最大三张数 | 6 | 同时约束飞机带单与带对 |
| 结算分数 | 开 | 关掉后只判胜负 |
| 抢地主模式 | **开** | 关掉回到 1/2/3 分叫分 |
| 明牌 / 加倍阶段 | 开 | 关掉则地主确定后直接开打 |
| AI 难度 | 1（均衡） | `0 保守` / `1 均衡` / `2 激进` |

**AI 难度**：三个档位不是三份策略，而是一张权重表（`AiProfile`）传进同一个 `AiPolicy`，只改风格与紧迫感
（叫分 / 抢地主 / 明牌加倍的门槛、什么时候动炸弹、什么时候开始封杀快走完的人），**规则一行不改**。
门槛写成「相对基线的偏移」，基线取 `2 + (手牌数−17)×5/4`——因为控场分与手牌数强相关（3 人局 17 张均值 ≈2，
4 人局 25 张均值 ≈12），写死绝对值会让 4 人局人人叫 3 分。

## 界面

* **顶部座位条**：头像、名字、`地主/农民`、`明/倍/×4` 徽章、剩余张数与**始终显示**的累计分数；
  当前行动方金色呼吸描边，叫分 / 明牌阶段名字后跟一块**表态牌子**（`抢` / `不抢` / `N分` / `不叫`）。
* **状态行**：局面（轮到谁、地主、底分·炸弹·抢·局倍数、AI 档位）+ 右侧**当前选牌的即时反馈**
  （`对子（2 张 · 可压）`）。
* **牌带**：手牌两行两段（后排只露左上角点数）、出牌区、上一手；底牌不占整行，是面板右上角的小牌预览。
* **右侧按钮列**：叫分 / 抢地主、明牌·加倍·确认、出牌·不出·提示·撤回·整理（互斥显示，都有 tooltip）。
* **记牌器**：15 个点数各剩几张没露面，由「你能看到的一切」推算（含别人明牌的手牌与地主底牌）。
* **看牌界面**（`看牌` 徽章或 `V`）：一页摊开每家的手牌与底牌——自己与已明牌的座位画正面牌，
  其余按真实张数画牌背；它是**独立界面**（和 Charta 的牌堆 / 历史界面同一套做法），`ESC` / 返回键 / `V` 回牌局。
* **手牌拖拽排序**：牌跟着鼠标走，手牌带上画插入位置箭头与竖线；拖过之后切到**手动牌序**
  （出牌只删掉打出去的那张，不再整手重排），`整理` 按钮回到点数顺序。
* **修掉的两个点击问题**：点第二行的牌却选中第一行、点上一手与底牌重叠处会「拿起」上一手的牌。

### 世界里的那张牌桌（不开界面也能看懂）

牌桌只有 1 格大，一张牌 0.156 格宽——**任何悬浮文字都比牌还大**，所以世界里一个字都不写，
局面全部用牌的位置与朝向表达：

| 想表达 | 做法 |
| --- | --- |
| 每家还剩几张 | 各座位扇形整局留在**自己的牌槽**里（不再往外推） |
| 谁是地主 | 地主面前**横放一张扣着的牌**（底牌本身摊在界面里：底牌预览 / 看牌页 / 聊天播报） |
| 上一手是什么、谁打的 | 摊在桌心，**偏向出牌者那一侧**并按出牌者的朝向摆放（不同人出的牌朝向不同）；收桌回中 |
| 现在轮到谁 | **轮到谁，谁那圈牌就往桌心推 0.19 格**，换人时上一家退回 |

所有摆位都以一个**固定的桌心常量**为基准（不拿会动的出牌区当中心），底牌标记的落点由出牌区落点推出来，
所以两者不会重合。

### 验证链（发布前全绿）

```powershell
# 工作目录：mods\chartalandlords
.\gradlew.bat clean build runGameTestServer dist   # 编译打包 + 34 个 GameTest + 发布产物
& ..\..\tools\logic-check.ps1                      # 440 项断言，零 Minecraft 依赖，毫秒级
& ..\..\tools\compile-check.ps1 -IncludeTests      # 离线 javac 编译校验
python tools\check_assets.py                       # 资源自检：.mccard 解码回像素逐字节对拍、牌堆 JSON、图标
```

* **`runGameTestServer` 在模组加载失败时仍报 `BUILD SUCCESSFUL`**（FML 崩溃后退出码仍是 0）——
  通过与否必须看日志里的 `All N required tests passed`。
* 资源由 `python tools\gen_assets.py` 生成（牌堆 JSON、`.mccard/.mcsuit`、选桌图标、模组 logo、
  项目图标 `src/main/resources/icon.png`、GameTest 空结构）；**发布产物里的 GameTest 类已被 `jar` 任务排除**。

### 硬规则

* **协议端口**：`Payloads.PROTOCOL_VERSION` 是握手版本，任何 payload 字段 / 含义变化、
  `DoudizhuAction` 顺序变化都要提升它（历史理由见该类注释）。
* **纯逻辑层**：`game/engine/` 里出现任何 Minecraft / Charta 类型，`logic-check.ps1` 会直接失败。
* **工具脚本 ASCII-only**：PowerShell 5.1 按系统码页解码无 BOM 的 `.ps1`，非 ASCII 注释会被误码。
* **字体/图标点阵**：`gen_assets.py` 的 5×7 字库只收录用到的字符，加新文字要补字形。
* 世界牌桌的摆位常量（推牌距离、底牌标记位置、出牌区偏移）都有 GameTest 盯着，改之前先看测试。

## 发布到 Modrinth

```powershell
$env:MODRINTH_TOKEN = 'mrp_...'   # scope: PROJECT_CREATE + PROJECT_WRITE + VERSION_CREATE
powershell -NoProfile -ExecutionPolicy Bypass -File tools\upload_modrinth.ps1 -DryRun   # 先干跑
powershell -NoProfile -ExecutionPolicy Bypass -File tools\upload_modrinth.ps1           # 真上传
```

上传 `dist\charta-landlords-<version>.jar` 与项目图标 `dist\charta-landlords-icon.png`；
项目页文案在 `modrinth/`（`summary.txt` / `description.md` / `changelog-*.md` / `upload.json` 里含
分类、MIT 许可、环境、游戏版本、加载器与 **required 依赖 Charta**）。默认建成**草稿**，看过页面再发布。

发布前检查清单：四条验证链全绿 → `gradlew dist` → 干跑核对字段 → 人眼在游戏里走完一局
（抢 / 叫分 → 明牌加倍 → 出牌 → 结算）。
